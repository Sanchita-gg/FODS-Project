# Project Outputs

This folder contains the output files generated during the EV Charging Demand and Revenue Optimization project.

## Files Included

- Final_EV_Demand_Predictions.csv
  Contains the final EV charging demand predictions generated by the machine-learning workflow.

- Final_Model_Comparison.csv
  Contains the performance comparison of the evaluated machine-learning models.

## Purpose

These outputs are used to examine predicted charging demand, compare model performance and support the interpretation of the project results.
