# Trained Machine Learning Models

This folder contains the trained machine-learning models developed for EV charging-demand prediction.

The models are used to predict:

- Total EV charging volume
- 11 kW reference charging volume

The trained Random Forest model files will be uploaded here.

## Model Files

The trained Random Forest models were saved locally in `.pkl` format using Joblib.

Due to file size or GitHub upload restrictions, the binary model files are not included in this repository. The model training and saving code is available in the ML notebook.
